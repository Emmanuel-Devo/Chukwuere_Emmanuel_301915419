Case Study: Emmanuel-Devo Store — E-commerce Order and Inventory Management System

Emmanuel-Devo Store is a simulated online retail business that sells products to customers through an e-commerce platform. The system manages customers, product categories, products, inventory levels, customer orders, order items, payments, and delivery records.

The main users are customers, store administrators, inventory staff, and order-processing staff. The database must support customer registration, product catalogue management, stock monitoring, order placement, payment recording, order tracking, and sales reporting.

The system will use PostgreSQL as its primary relational database for structured data, transactional processing, and SQL query optimization. MongoDB will support flexible product attributes and document-based data modelling. The project will also examine transaction management, concurrency control, indexing, query execution plans, and a proposed distributed or cloud database architecture using replication, sharding, availability, and consistency concepts.

The same case study will be used throughout all five MIT 8103 portfolio activities. The implementation will be developed and tested as an academic project, with SQL scripts, database models, test results, execution plans, screenshots, and technical documentation maintained in a private GitHub repository.
